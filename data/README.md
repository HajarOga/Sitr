# data/

Two folders, both ours, both synthetic.

| folder | what it holds | who reads it |
|---|---|---|
| `synthetic/` | the demo document, written by `python -m scripts.make_demo_document`. Arabic + English, with a table and Arabic-Indic digits. | the dashboard's sample picker, `scripts/smoke_test.py` |
| `test/` | a fixed test set generated by `python -m scripts.make_test_set`. Labels are exact by construction: the generator records every value as it writes it. | reserved — **no evaluation harness is built in this version**, so nothing scores against it yet; it is here so a future harness has a fixed set to measure |

Rules this folder follows:

- **Everything here is invented.** No real person's data, no real company document. The
  replacement values are reserved test values (`0500000000`, `1000000000`,
  `SA00 0000 …`, `example.test` addresses) and the IBAN substitute is deliberately *not* a
  valid IBAN, so it can never be mistaken for a live account.
- **`test/` is never trained on and never written to.** In this build the model is not
  fine-tuned at all — it is used as shipped — but the rule stays as a guard against a
  future training step reading the wrong folder. `tests/test_safeshare2.py` covers the
  audit and release behaviour around it.
- **Nothing here is uploaded anywhere.** The model runs locally, and the files in this
  folder are read by the app on this machine only.

If you generate more demo material, keep it here and keep it synthetic.
