# Sitr (سِتر) - dependencies
#
# The model is mandatory in this build, so torch/transformers are core dependencies here
# (in the first prototype they were optional extras).
#
#   app        the pipeline, the dashboard, the API, the audit log
#   model      Qwen2.5-3B-Instruct - the *local* provider. Installed separately with
#              `python -m scripts.setup_model` (the weights are ~6 GB and are not in git).
#              With SAFESHARE2_PROVIDER=api these libraries are never imported: the model
#              is called over HTTP with httpx instead.
#   policy     Chroma plus a multilingual embedding model - the policy index behind the
#              Policy page's questions and rule editing. Also installed by
#              `python -m scripts.setup_model` (the embedder, ~470 MB).
#   documents  PDF reading, DOCX reading/writing, the audit table in the dashboard
#
# These are the versions this build was run and tested against (Python 3.13, macOS
# arm64). They are pinned exactly because they work together: pip cannot resolve
# transformers 5.x against torch 2.10, which is why the two move as a pair. If you change
# one, run the test suite and `python -m scripts.smoke_test` before you keep it.
#
# After your own successful install, `pip freeze > requirements.lock.txt` and keep that
# next to this file - that is the exact environment you demonstrated.
